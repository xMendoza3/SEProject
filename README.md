# المستكشف الفقهي المقارن

تطبيق يقارن أقوال المذاهب الأربعة في المسائل الفقهية، من كتاب "الفقه على المذاهب الأربعة" لعبد الرحمن الجزيري.

## المزايا

- تصفح أبواب الكتاب كشجرة: القسم، ثم الكتاب، ثم المباحث
- زر رجوع يعيدك للمكان اللي كنت فيه، مثل زر الرجوع في المتصفح
- البحث في العناوين وفي نصوص الأقوال، مع تجاهل الحركات وتوحيد الهمزات
- اختيار المذاهب المراد مقارنتها، من مذهب واحد إلى أربعة
- عرض الأقوال جنباً إلى جنب، مع الأقوال المشتركة بين أكثر من مذهب
- زر عرض الدليل للآيات والأحاديث الواردة في كل قول
- توثيق كل قول بالجزء والصفحة، مع رابط الصفحة نفسها في المكتبة الشاملة
- نسخ أي قول مع عنوان بابه ومصدره ورابطه، للصق في أي محادثة
- المفضلة مع ملاحظات شخصية
- تصدير الباب أو المفضلة إلى ملف وورد أو PDF، بخط عربي مشكّل
- زخارف هندسية إسلامية خفيفة في الخلفية وتحت العناوين، مبنية من النجمة الثمانية
- يعمل على الجوال، ويمكن إضافته إلى الشاشة الرئيسية بأيقونته
- خريطة كرة أرضية تفاعلية لانتشار المذاهب، وكل منطقة معها كلام المصدر ورقم صفحته. الخريطة وحدها تحتاج إنترنت
- نبذة عن كل إمام من الأئمة الأربعة: نسبه وعصره، وشيوخه وتلاميذه، وطريقته في الاستنباط، وانتشار مذهبه. تفتح بالضغط على اسمه في شاشة البداية

## التشغيل السريع على ويندوز

اضغط ضغطتين على الملف التالي في مجلد المشروع:

```
run.bat
```

أول مرة ينشئ البيئة، ويثبّت المكتبات، ويبني قاعدة البيانات. تثبيت المكتبات يحتاج إنترنت مرة واحدة فقط، وبعدها يعمل التطبيق دون اتصال.

## التشغيل اليدوي

يحتاج بايثون بإصدار ٣٫١٠ أو أحدث.

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python ingest.py
streamlit run app.py
```

## الاختبارات

اختبارات آلية لكل طبقة، على كتاب صغير مصطنع وقاعدة بيانات في الذاكرة، فلا تلمس ملفات المشروع. تثبيت مكتبة الاختبارات مرة واحدة، ثم التشغيل:

```
pip install -r requirements-dev.txt
python -m pytest
```

## طريقة العمل

ملفات الكتاب الخام مرفقة مع المشروع في مجلد البيانات. ملف الاستيراد يمرّ عليها بخمس مراحل، والخامسة تحمّل حدود المحافظات للخريطة:

```
1. Fetch    data/raw (or turath.io if missing)
2. Parse    pages -> main text + footnotes, chapter tree
3. Extract  text blocks -> madhab opinions + evidence
4. Save     SQLite database (data/fiqh.db)
5. Map      data/raw/boundaries (or geoboundaries.org if missing)
```

الاستخراج يعتمد على قواعد نمطية لا على الذكاء الاصطناعي، لأن المؤلف يكتب بقالب ثابت: اسم المذهب ثم "قالوا". والمبدأ الحاكم هو الدقة قبل الشمول: أي نص لا يُعرف صاحبه بثقة يبقى في نص الباب ولا يُنسب لمذهب.

## البنية

بنية طبقية تجمع نمط النموذج والعرض والمتحكم مع نمط المستودع:

```
app.py               View        Streamlit interface (AppView)
src/controllers.py   Controller  ExplorerController, ImportController
src/database.py      Repository  DatabaseManager (SQLite)
src/scraper.py       Service     FiqhScraper, BoundaryScraper
src/map_data.py      Repository  MapRepository (data/madhab_map.json)
src/profiles.py      Repository  ProfileRepository (data/imam_profiles.json)
src/parser.py        Service     PageParser
src/extractor.py     Service     OpinionExtractor
src/exporter.py      Service     Exporter (decides the content of exported files)
src/writers.py       Service     DocumentWriter, DocxWriter, PdfWriter (Builder pattern)
src/ornament.py      Utility     star_outline (eight-pointed star, for the UI and the PDF)
src/models.py        Model       Madhab, Page, TextBlock, Chapter, Opinion, Evidence, Bookmark,
                                 Source, MapRegion, MapMention,
                                 ProfilePoint, ProfileSection, ImamProfile
ingest.py            Entry point for the import
tests/               Automated tests (pytest)
static/icon.png      App icon
static/fonts/        Amiri font for PDF files, with its license (OFL)
```

## المصدر

- الكتاب: الفقه على المذاهب الأربعة، عبد الرحمن بن محمد عوض الجزيري، دار الكتب العلمية، الطبعة الثانية
- النسخة الرقمية: من موقع تراث، وهي مطابقة لنسخة المكتبة الشاملة في الترقيم
- خريطة المذاهب: أحمد تيمور باشا، نظرة تاريخية في حدوث المذاهب الفقهية الأربعة وانتشارها عند جمهور المسلمين، الخاتمة من ص٨٦ إلى ص٨٩، والكتاب في المكتبة الشاملة. وكل كلام منسوب للمؤلف في الخريطة يتأكد منه اختبار آلي حرفاً حرفاً
- حدود المحافظات: مشروع جيو باوندريز المفتوح، وأصلها من خرائط الشارع المفتوحة
- خط ملفات الـ PDF: خط أميري، برخصة الخطوط المفتوحة، ورخصته مرفقة معه في مجلد الخطوط
- نبذة الأئمة، والصين في الخريطة: عمر سليمان الأشقر، المدخل إلى دراسة المدارس والمذاهب الفقهية، دار النفائس، الطبعة الثانية ١٤١٨هـ. النبذة ملخصة بكلامنا، وكل نقطة معها رقم صفحتها

## حدود معروفة

- في الحواشي الطويلة قد يلتصق تعليق المؤلف بآخر قول قبله
- نحو ١٪ من الأقوال تحتوي كلاماً لمذهب آخر لم يمكن فصله بأمان، بسبب الترقيم في النص الأصلي
- يُلتقط الحديث فقط إذا جاء بين علامتي تنصيص بعد رمز الصلاة على النبي مباشرة
- في النسخة المنشورة على الإنترنت، المفضلة مشتركة بين كل الزوار، وتُمسح كلما أُعيد تشغيل الخادم. على الجهاز الشخصي تبقى دائماً

## تنبيه

تقسيم الأقوال آلي، والمرجع هو نص الكتاب. التطبيق للدراسة والمقارنة، وليس بديلاً عن سؤال أهل العلم.
